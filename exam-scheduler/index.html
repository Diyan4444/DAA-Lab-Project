Imagine a college where some students take both Maths and Physics. If those two exams are on the same day and time, those students are stuck. This tool finds a timetable where that never happens. It does this by drawing a map: each subject is a bubble, and a line joins two subjects if any student takes both. Bubbles joined by a line get different colors, and each color is one exam time. Same color = can safely be held together.

❓ Frequently Asked Questions
1. What do I type in?
Just type each student's name followed by a colon and their subjects separated by commas. For example: Riya: Maths, Physics, Chemistry. You can also upload a standard spreadsheet CSV file with headers student_id,subjects.
2. What if two subjects have the same name spelled with different capitals?
The tool automatically treats 'maths', 'Maths', and 'MATHS' as the exact same subject. You don't need to worry about capitalization.
3. Why does the timetable need more exam times than I expected?
If many students take multiple subjects together, those subjects cannot happen at the same time without causing clashes. The tool calculates the minimum number of exam times required to keep everyone 100% clash-free.
4. Can I change the exam times or dates?
Yes! In the Settings card on the left, you can change the first exam date, set how many exams happen per day (1 to 4), toggle weekend skipping, or click "Change exam timings" to edit the exact morning/afternoon hours.
5. Is my data uploaded anywhere?
No, absolutely not. Everything runs 100% inside your web browser on your own computer. No data is ever sent to any server, database, or external service.

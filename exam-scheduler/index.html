Frequently asked questions

1. What do I type in?
Type each student's name followed by a colon and their subjects separated by commas. For example: Riya: Maths, Physics, Chemistry. You can also upload a spreadsheet CSV file with headers student_id,subjects.
2. What if two subjects have the same name spelled with different capitals?
The tool automatically treats 'maths', 'Maths', and 'MATHS' as the exact same subject. Capitalization differences are resolved automatically.
3. Why does the timetable need more exam times than I expected?
If many students take multiple subjects together, those subjects cannot happen at the same time without causing clashes. The tool calculates the minimum number of exam times required so that no student ever has two exams at the same time.
4. Can I change the exam times or dates?
Yes. In step 2 on this page, you can change the first exam day, choose how many exams happen per day (1 to 4), toggle weekend skipping, or open "Change exam hours" to edit the exact morning and afternoon time windows.
5. Is my data uploaded anywhere?
No, never. Everything runs directly inside your web browser on your own computer. No student names or data ever leave your device or travel over the internet.

How does this work?
  1. Each subject is a bubble.
  2. If any student takes two subjects, we join their bubbles with a line.
  3. Joined bubbles get different colors. Each color is one exam time, so subjects with the same color can safely be held together.
